# ProjetoLoja — protótipo de vitrine

Este repositório estava vazio. Foi criada uma demonstração estática responsiva de catálogo, filtros, carrinho com persistência local e preparação de pedido para copiar/compartilhar.

## Limites
- Produtos, preços e identidade são **fictícios**.
- Não há banco, autenticação, pagamento, controle de estoque nem processamento de pedidos.
- Não há número de WhatsApp configurado: a mensagem pode ser copiada ou compartilhada manualmente.
- O carrinho é salvo apenas no navegador (localStorage).

## Testes e publicação
Abrir `index.html` em navegador moderno. Antes de usar comercialmente, substituir os produtos e preços, cadastrar contato oficial, validar acessibilidade e testar em dispositivos reais. O site é compatível com hospedagem estática, mas não foi publicado no GitHub Pages nesta etapa.
